# Design brief — Waypoint

## What it is
Waypoint is an unofficial onboarding hub for Thru (a RISC-V Layer-1). Five short missions on a live test network teach a newcomer to create a passkey wallet, receive funds, send a transfer, find a token account and move a token. Every result is verified from on-chain data, with no server, database or login. A "Lab" lets them see the network's real strengths (a live oracle price board, a transaction taken apart, a RISC-V program read as instructions). Project type: developer/web3 education hub with a product flow (domains.md: crypto / web3 + developer tool).

## Who, where
Curious developers and crypto-adjacent newcomers on a laptop, often at a hackathon or following a tweet. They know what a wallet is; they do not know what makes Thru different and are wary of seed phrases and extensions. They judge a chain project in seconds by how credible and current the site looks.

## The one job
Understand in five seconds that this is a guided, hands-on trail through Thru, and start mission 1.

## The specific truth
Nothing here is taken on trust: progress is recomputed from the chain on every visit, and a receipt link re-reads the chain. The product is a *route* (ordered stops) whose proof is *public data*.

## Content inventory (only what exists)
- Words: "Learn Thru by using it." · five mission titles and goals · three Lab instruments · "Nothing to take on trust" (no server, no database, no login; failed transactions do not count) · unofficial disclaimer.
- Things to look at: the five missions with states (verified, active, locked); a receipt; the Lab (price board, transaction anatomy, program disassembly).
- Things to do: Start the trail, Open the Lab, Verify a mission.
- Real facts: only those in the README (what each mission reads from the chain). No user counts, no logos, no quotes.
- Missing, to be produced: brand mark, hero visual, per-section visuals, receipt art.

## Flows
1. Land → Start trail → mission 1 (create wallet) → verify → next.
2. Land → Open Lab → watch live instruments → go to the trail.
3. Open a shared receipt link → see what the chain says.

## The world
Waypoints, cairns, route markers, contour lines, trailheads, compass bearing, passkey, fingerprint, signature, receipt, stamp, ledger line, program counter, register, opcode, byte, slot, oracle feed, price tick, faucet, vault, token account, explorer link, block height.

## Looking around (principles, not looks)
Could not browse galleries from this sandbox; principles taken from the skill's catalogs and from adjacent media (survey maps, engineering drawings, passports, die shots).
| Studied | Principle extracted | Not taking |
| --- | --- | --- |
| Survey and trail maps | a route is a sequence of verified points, drawn once and reused as navigation | any specific cartography brand |
| Engineering title blocks | provenance printed on the artefact itself | blueprint-blue cosplay with glow |
| Passports and postage | proof is collected, dated and individual | tilted paper stickers |
| Die shots / chip photography | one object, many layers, depth explains structure | stock 3D chips |

Useful conventions to keep: a clear start action, visible network status, wallet passkey explained in one line. Empty conventions to break: dark neon grid, three icon cards, token tickers as decoration.

## Candidate ideas ("this is a Y")
1. Waypoint is a **field guide to a landscape** (map, route, bearing).
2. Waypoint is a **first wallet in your pocket** (friendly, tactile, badges).
3. Waypoint is a **drawing of the machine** (annotated schematic of the chain).
4. Waypoint is a **single precious object under glass** (a die, layered, lit).
5. Waypoint is a **catalogue of stamps** (numbered index, proof you collect).
6. Waypoint is a **flight recorder** (every action logged, replayable). Not chosen: too close to a data dashboard.

Chosen five: Survey, Pocket, Cyanotype, Obsidian, Stamp Index. Brave: Pocket (breaks the "serious dark chain" convention with a playful consumer language). Quiet: Stamp Index (monochrome, one asset system, almost all type).

## Autopilot, named and set aside
Visual: near-black ground, one neon accent, glowing grid, mono labels everywhere, tickers (attractor C). Nearest neighbour: dark purple gradient web3 landing (B). Also the earlier "Redline" direction used for the first build is not repeated.
Content: stats band, "trusted by" logos, three icon feature cards, testimonials, roadmap. None is justified by the inventory.
